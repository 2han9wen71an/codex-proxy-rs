# v3.13.0+cpr.1

> Fork 集成版本：基于上游 v3.13.0（main @ 16fa303a），合并 PR #192、#161、#223。

## 新增功能（相对上游 main）

- Codex 会话亲和开关（PR #223）：新增运行设置 `codexSessionAffinityEnabled`，默认开启保持现有行为；关闭后同一会话不再钉在首个账号上，每个请求按调度策略（轮询等）重新分配账号，多账号用量更均匀。Codex 的 prompt cache 跨账号有效，关闭亲和没有缓存损失
- 账号定时预激活（PR #192）：每日指定时间对 OAuth 账号发起极微小请求，提前启动 5h 配额滑动窗口，最大化全天可用额度
- PAT 账号可配置 Web Access Token（PR #161）：PAT 账号也能使用网页端额度重置能力

## 升级说明

- 从上游 v3.13.0 升级会自动执行 0017（账号预激活）、0018（会话亲和开关）两个数据库迁移，无需手工调整
- 关闭会话亲和：管理端 → 设置 → 网关调度 → Codex 会话亲和
- 本版本的在线更新检查指向上游仓库，请勿使用管理端「在线更新」升级（会回到上游版本）；升级请拉取本 Release 附件或镜像
